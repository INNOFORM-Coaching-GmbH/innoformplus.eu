# innoformplus.de

Statische Landingpage von Innoform Plus, ausgeliefert über GitHub Pages (eigene Domain www.innoformplus.de, siehe `CNAME`).
Keine Datenbank, keine Schriften oder Skripte von außen. Kauf, Konto und Lernen laufen in E2G (innoform-coaching.de).

- `index.html` – die Seite; alle Links nach E2G stehen gesammelt unten in `LINKS`.
- `fonts/` – Lato (SIL Open Font License, `fonts/OFL.txt`), `abzeichen/` – Trophäen aus E2G, `innoform-logo-weiss.png`.
- Vorabversion: `noindex` in `index.html` und `robots.txt` sperren Suchmaschinen. Vor dem offiziellen Start beides entfernen.

Änderungen: Zweig → PR → Merge auf `main`; GitHub Pages veröffentlicht `main` nach ein bis zwei Minuten.
